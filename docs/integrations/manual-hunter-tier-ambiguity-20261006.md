# Manual-hunter review-tier ambiguity fix

- **Feature branch:** `fix/manual-hunter-tier-ambiguity-20261006` (based on `origin/beta` at `59e72403600c9e9035081ca32e7ac5c64f3bbd83`).
- **Scope:** `agents/manual_hunter.py` and `agents/test_manual_hunter.py`; no change to `sync_reports` import or stored finding records.
- **Current defect:** A note describing an observed/reproduced cross-account read and saying its impact *may* extend was silently classified `DORMANT_HYPOTHETICAL` because broad uncertainty markers in description overrode the actual proof. A synthetic current-beta repro demonstrated the mis-tier; no live target was touched.
- **Fix:** If no explicit Review Tier or structured blocker is supplied, and the narrative has both inference-level uncertainty and proof language, reject before creating a finding with an actionable `Review Tier` instruction. An author must explicitly select `CONFIRMED` for observed proof or `DORMANT_HYPOTHETICAL` for unproven claims. Pure hypothetical notes without proof language retain the existing inferred tier. No auto-promotion based on evidence keywords alone.
- **Red/green:** New parse regression failed before change (`ValueError not raised`) and passed afterward. `agents/test_manual_hunter.py`: 25 passed, 9 subtests. `agents/test_sync_reports.py` has two canonical-report-format failures reproduced unchanged on beta; `agents/test_dormant_split.py` has one navigation-link-format failure reproduced unchanged on beta. These are unrelated baseline defects, not repaired here.
- **Risk/rollback:** An ambiguous evidence-bearing manual note without `Review Tier:` now errors instead of saving a potentially mis-tiered finding. Add the explicit field to that note; if regressions arise, revert the feature commit. This does not re-tier existing findings. Human review still determines whether the asserted proof truly supports the claim.
- **Reviewer focus:** Assess whether the guard prevents silent downgrade without promoting hypothetical notes; inspect explicit-tier override, pure-hypothesis compatibility, and any other caller of `_infer_review_tier` before beta publication.
