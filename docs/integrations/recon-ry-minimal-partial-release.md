## Explicit residual limitations and blockers

1. **Legacy fuzz/no-program:** with a working validator, `run_campaign.py` may instantiate `FuzzAgent` without a program and therefore without its saved-scope validator; the separate `HarnessConstraints` check is not a demonstrated replacement. Path exclusions and campaign/program authorization need a separate fix and independent verification. Other consumer no-program paths are likewise not certified.
2. **Globally missing IDNA diagnostics:** the import guard handles failures encountered while importing the validator, but when `idna` is globally absent, other top-level HTTP imports in direct-script entry points can fail first with an unhelpful raw missing-module error. Prior review identified this; do not claim it fixed. The source guard covers fail-closed scope behavior, not every diagnostic path.
3. **Path-restricted scope is unsupported for Recon-Ry launch:** named path/origin/port restricted scope and mixed scope are refused wholesale by the wrapper, so otherwise permitted portions are not covered by that workflow. Use a separately reviewed request-contained method; no such method is asserted here.
4. **Provisioning:** the root manifest adds `idna>=3,<4`; an existing runtime is not updated by a manifest commit. After separately authorized integration and before activation, provision that actual checkout using `./setup.sh --install-python-deps`, verify dependency versions, Bounty Core pin and actual fresh-process module origins, and rerun focused tests. No installation or runtime activation was performed.
5. **Snapshot and redirects:** repeated saved-scope reads/signature checks are not atomic and cannot detect every concurrent change, particularly after the final read or during detached queues. Host filters do not constrain every redirect, subresource, nested tool, or scheme/port request. Secrets Finder's Wayback/Nuclei entry points have existing scope-enforcement gaps even when the validator loads. No egress confinement or comprehensive redirect safety is claimed.
6. **Missing independent security review:** a fresh reviewer must inspect the entire candidate diff and original dossiers, challenge consumer import failures, scope/redirect/path behavior and operational tradeoffs, and rerun the offline suites. The parser test used a local checkout only; Hoster revision/profile behavior remains unverified. Review and any release decision belong to the parent. Independent review is mandatory even if all tests pass.
