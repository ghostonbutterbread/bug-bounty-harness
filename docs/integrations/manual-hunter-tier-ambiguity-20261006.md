# Manual-hunter review-tier ambiguity fix

- **Feature branch:** `fix/manual-hunter-tier-ambiguity-20261006` (based on `origin/beta` at `59e72403600c9e9035081ca32e7ac5c64f3bbd83`).
- **Scope:** `agents/manual_hunter.py`, `agents/sync_reports.py`, and their focused tests. Existing stored findings are not re-tiered.
- **Current defect:** A note describing an observed/reproduced cross-account read and saying its impact *may* extend was silently classified `DORMANT_HYPOTHETICAL` because broad uncertainty markers in description overrode the actual proof. A synthetic current-beta repro demonstrated the mis-tier; no live target was touched.
- **Fix:** An invalid explicit tier is rejected before any missing-field or loose fallback can guess a tier. Neutral `Exploitability`, `Blocked Reason`, and `Chain Requirements` are normalized before inference, not merely in the ambiguity guard. For an unlabelled note with uncertainty and an evidence signal (structured PoC/Review Notes or an observed-response phrase), the author must explicitly select `Review Tier:`; a bare unproven *may/might* claim continues to infer `DORMANT_HYPOTHETICAL`. `sync_reports` skips unresolved notes with an actionable error and nonzero return, but honors valid per-finding `[CONFIRMED]`/`[DORMANT_...]` Markdown headings instead of whole-file loose-parser ambiguity. No automatic promotion of uncertain claims.
- **Red/green:** Original synthetic regression failed before the initial change. First review exposed neutral-field/loose-fallback bypasses; second review exposed neutral-field mis-inference, pure-hypothesis rejection, missing-description invalid-tier bypass, and structured-heading loss. All had focused RED tests and passed after repair. Combined `agents/test_manual_hunter.py agents/test_sync_reports.py`: 49 passed, 13 subtests, two canonical-report-format failures reproduced unchanged on beta. `agents/test_dormant_split.py` has one navigation-link-format failure reproduced unchanged on beta. These unrelated baseline defects are not repaired here.
- **Risk/rollback:** An ambiguous evidence-bearing manual note without `Review Tier:` now errors instead of saving a potentially mis-tiered finding. A batch sync returns nonzero if any file needs an explicit tier, after processing other files; inspect its summary before retrying. If regressions arise, revert the feature commits. Human review still determines whether asserted proof supports a claim.
- **Reviewer focus:** Re-review the neutral-field guard, invalid-tier rejection, proof phrasing, pure-hypothesis compatibility, and `sync_reports` skip/no-fallback behavior before beta publication. The separate class-inference concern in `PC-20260903-231406-e31c245a` is not resolved by this tier-only patch, so the whole report must not be closed.
