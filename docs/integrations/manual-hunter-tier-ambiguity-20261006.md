# Manual-hunter review-tier ambiguity fix

- **Feature branch:** `fix/manual-hunter-tier-ambiguity-20261006` (based on `origin/beta` at `59e72403600c9e9035081ca32e7ac5c64f3bbd83`).
- **Scope:** `agents/manual_hunter.py`, `agents/sync_reports.py`, and their focused tests. Existing stored findings are not re-tiered.
- **Current defect:** A note describing an observed/reproduced cross-account read and saying its impact *may* extend was silently classified `DORMANT_HYPOTHETICAL` because broad uncertainty markers in description overrode the actual proof. A synthetic current-beta repro demonstrated the mis-tier; no live target was touched.
- **Fix:** An invalid explicit tier is rejected. When uncertainty and evidence/impact-extension language coexist without a substantive structured blocker, an unlabelled note requires an explicit `Review Tier:` rather than a guessed tier. Neutral `Exploitability`, `Blocked Reason`, and `Chain Requirements` do not suppress the guard; proof phrasing in Review Notes and PoC is considered. Pure one-line hypothetical notes still retain their inferred tier. `sync_reports` now skips the affected file with an actionable error and nonzero return instead of falling back to a guessed tier; it may continue importing other files. No auto-promotion based on evidence keywords alone.
- **Red/green:** Original regression failed before the initial change. Independent review found four material bypasses; focused RED tests covered neutral fields, `appears to`, invalid explicit tiers, and loose-import fallback. After repairs, `agents/test_manual_hunter.py` passed 28 tests plus 9 subtests; the new sync-reports rejection test passed. Full manual-hunter + sync-reports suite had 43 passed, 2 failed; the two canonical-report-format failures reproduce unchanged on beta. `agents/test_dormant_split.py` also has one navigation-link-format failure reproduced unchanged on beta. These unrelated baseline defects are not repaired here.
- **Risk/rollback:** An ambiguous evidence-bearing manual note without `Review Tier:` now errors instead of saving a potentially mis-tiered finding. A batch sync returns nonzero if any file needs an explicit tier, after processing other files; inspect its summary before retrying. If regressions arise, revert the feature commits. Human review still determines whether asserted proof supports a claim.
- **Reviewer focus:** Re-review the neutral-field guard, invalid-tier rejection, proof phrasing, pure-hypothesis compatibility, and `sync_reports` skip/no-fallback behavior before beta publication. The separate class-inference concern in `PC-20260903-231406-e31c245a` is not resolved by this tier-only patch, so the whole report must not be closed.
