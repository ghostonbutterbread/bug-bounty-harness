## Intent and implemented contract

Package and direct-script consumers now import their sibling validator and retain import exceptions. Fuzz, AI recon, autonomous recon, Google dorking, subdomain collection and LLM harness reject a missing validator with an actionable requirements diagnostic and chained cause before their network work; validator initialization failures propagate. The check also rejects a missing validator when the program argument is absent. No authority to run unscoped is implied by a working import.

Secrets Finder retains local file/directory and URL-list analysis when the validator cannot import. Its scope check, Wayback query/fetch entry points, Nuclei launch and TruffleHog launch refuse that failure before network/process work. TruffleHog filesystem mode is guarded too because it may verify secrets externally. Gitleaks is left as a local subprocess. The guard is availability-only: it does not prove the remote target is in scope.
